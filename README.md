# AlphaNumericPassword_Python

A small Python script that asks for a length and prints a random password made of upper/lowercase letters and digits. Characters are picked with the `secrets` module, which is suitable for generating passwords. Written as a learning exercise.

## Tech stack

- Python 3 (standard library: `secrets`, `string`)

## How to run

```bash
python main.py
```

Enter the required password length when prompted.
